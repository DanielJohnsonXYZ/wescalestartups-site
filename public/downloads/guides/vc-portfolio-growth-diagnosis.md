# VC Portfolio Growth Diagnosis Template

We Scale Startups · Free workshop format (~90 minutes)

## Five founder prompts
1. Could the team run pipeline for a month without the founder?
2. Does more than one channel reliably create pipeline?
3. Do you know, with evidence, why customers pick you?
4. Which dashboard does the team trust — and who owns it?
5. What decision has been stuck for more than two weeks?

## Route after diagnosis
- Unclear constraint → Growth Diagnosis
- Need signal this quarter → 90-Day Sprint
- Channels exist but no rhythm → Acquisition System Build
- Need senior seat → Fractional CMO
- Wrong fit → referral, not force-fit
