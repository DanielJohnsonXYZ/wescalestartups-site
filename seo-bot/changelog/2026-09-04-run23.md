## 7. Method correction — the GSC UI's live table is the VISIBLE one, not the last one

Run 22 established: *"Tables come back in load order; the last one is the live view."* **That is wrong often enough to be dangerous, and it failed twice this morning.** After switching to the Pages tab, `document.querySelectorAll('table')` returned four tables and the **last** was the stale Days table; the live Pages table was index 2. Earlier, table 0 was the 693-row 3-month query set — the same stale container that fed run 22's misleading `get_page_text` result.

**The correct discriminator is visibility:**

```js
const live = [...document.querySelectorAll('table')]
  .find(t => t.offsetParent !== null && t.getBoundingClientRect().height > 0);
```

Stale containers are retained in the DOM at zero height with `offsetParent === null`. Verified against four different tab states. `get_page_text` remains unusable on this page. Playbook updated.
