## 1. THE PANEL WAS MEASURING ITSELF, NOT GOOGLE — sixth false fact, and this one is an instrument defect

The playbook carries this as a standing instruction, promoted to a headline finding by run 19:

> **READ THE WINNABLE SURFACE, NOT THE SHARE.** Google returns zero external citations on prompts **2, 5, 6 and 10** — 4 of 10 ungrounded, unwinnable by anyone. The surface has gone **10 → 7 → 6**.

**It has not.** This reading, run with explicit waits and a scroll to the end of the response, found the winnable surface at **9 of 10**. Only prompt 6 is genuinely ungrounded. Prompts 2, 5 and 10 all render external citations and, in prompt 5's case, a full ranked vendor list with WSS at the top of it.

**The mechanism.** Google AI Mode streams its answer. `get_page_text` called shortly after navigation returns whatever has rendered so far, **with no marker that the response is incomplete**. The first read of prompt 5 this run returned text ending at the heading `Consultancies & Specialized Partners` — the heading present, the three vendors under it absent. Read at that moment, prompt 5 scores as "no vendors named, no citations rendered." Read fifteen seconds later after a scroll, it scores as **WSS named first, `/facts/we-scale-startups` cited as the top source**. Same prompt, same session, four minutes apart.

That is exactly the sentence run 19 wrote about prompt 5 — *"returned a pure framework answer with zero vendors named and zero citations rendered. Nobody won it."* It is far more likely that run 19 read a still-streaming page than that Google served a vendor-free answer that day and a vendor-led one today.

**Consequences, stated at the confidence they deserve:**

- **VERIFIED: a panel reading taken without confirming the response has finished is unreliable, and this run reproduced the failure directly.** Prompt 1 was also truncated on first read this run (ended mid-sentence at `Deep Dive: Choosing the Right Fit…`) and was re-run. Prompt 9 **stalled outright** at an ellipsis after 40 seconds and had to be re-issued; a run that scored that page would have logged "WSS not named" for what was not an answer at all.
- **INFERRED: the "shrinking winnable surface" finding (10 → 7 → 6) is an artefact, not a property of Google.** It has the signature of one — it moves monotonically in the direction of "less rendered", which is what you get when reads get faster relative to a streaming response, and it reverses completely the moment the read waits. n is two readings; do not treat the reversal as proven either.
- **The share numbers for readings #3 and #4 are downgraded, not voided.** A truncated read can only ever *undercount* mentions. So `2/10` and `1/10` are floors, and the true figures for those readings are unknown and probably higher.

**New standing rule, added to the playbook:** *an AI Mode response is not readable until it is finished. Wait, scroll to the bottom, and require a completion tell — the follow-up question block ("To recommend…", "could you share…"), the copy/share/thumbs icon row, or the rendered sources card — before scoring any prompt. A prompt with no completion tell is a null reading and must be re-issued, never scored as an absence.*

This is the sixth false fact this project has found in its own playbook, and the first that was not a half-truth about the site but a defect in how the site was being measured. The others produced wrong beliefs; this one produced a wrong headline metric that the playbook then instructed every future run to report.
