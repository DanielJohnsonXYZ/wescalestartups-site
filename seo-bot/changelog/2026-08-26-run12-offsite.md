# 2026-08-26 (run 12) — the off-site profiles, opened for the first time

Daniel asked for the Google Business Profile and Clutch work to be done directly in the browser. **Every assumption in backlog 3 was wrong**, and finding that out was worth more than the changes.

## Backlog 3 was wrong: the profiles already exist

Since run 6 the playbook has said off-site presence needs *building*. It does not. All of these already existed, and all are claimed:

| Profile | State found |
|---|---|
| Google Business Profile | **Verified, claimed**, 5.0 from 2 reviews, 840 views, 228 customer interactions |
| Clutch | `clutch.co/profile/we-scale-startups` — 5.0 from 1 verified review (Weather Factory, gaming, 2021) |
| Trustpilot | Claimed since Oct 2020 — **3.5 from 4 reviews, including a one-star** |
| Facebook | 39 followers, admin access |
| Instagram | `@wescalestartups` |
| X (company) | `x.com/wescalestartups` — distinct from Daniel's `@djohnsonxyz` |
| Crunchbase | Exists, Cloudflare-challenged, URL unverified |

**The constraint was never absence. It is drift.** Three of these disagree with the site and with each other.

## The finding: three different founding years

| Source | Founded |
|---|---|
| Site schema, LinkedIn | 2016 |
| Google Business Profile | 2018 → **fixed to 2016** |
| Clutch | **2019** — still wrong |

For a business whose entity is already contested by three unrelated WeScale companies, publishing three founding years across its own profiles is self-inflicted. `foundingDate` is one of the few hard disambiguators available and it was being contradicted by the firm itself.

**Caveat on the GBP fix:** Google's help text for that field reads *"the date that you opened or will open at this address."* If WSS moved into 81 Curtain Road in 2018, 2018 was correct for GBP and the two fields were measuring different things. Daniel chose 2016 and it is one click to revert; flagged to him rather than buried.

## Still open

- **Clutch: founding year 2019, hourly rate `$50–$99/hr`, min project `$1,000+`.** The rate band is the worse problem — against £2k–£25k fixed-scope engagements it reads as a different, far more junior business. **Blocked:** the 1Password integration returned `transport_error / retryable` on every attempt and the browser has no Clutch session.
- **Trustpilot 3.5 from 4 reviews, with "no recent history of asking for reviews."** Weakest public rating, indexed by Google, and the highest-leverage place to run review outreach — ahead of Clutch. Deliberately **not** added to `sameAs`: that is an identity statement rather than a reputation one, Google indexes the page either way, and actively linking a 3.5 is Daniel's call.
- **Two more inconsistencies found in passing.** Facebook lists `hello@wescalestartups.com`; the site schema uses `daniel@wescalestartups.com`. And a live post from 19 Dec 2022 still contains **"Lorem Ipsum"** placeholder text in its body.

## Method notes for future runs

- **The GBP edit modal renders taller than an 812px viewport with no internal scroll**, so Save is unreachable. `resize_window` does not help past screen height. Fix: `document.body.style.zoom='0.65'` via `javascript_tool`, which brings the whole dialog into view. This is what unblocked every GBP change in this run.
- **The GBP service panels load asynchronously and silently discard input typed before they render.** Two edits were lost this way. Wait for the field labels to appear in a screenshot before typing.
- **The Google account holds six business profiles and the Facebook account a dozen-plus pages.** `business.facebook.com/latest/settings` opened a completely unrelated portfolio (*gatherr / Kleyo Ltd*). Always confirm which entity is on screen before editing.
- **Crunchbase serves a Cloudflare bot challenge.** Not to be worked around; leave those URLs to Daniel.
