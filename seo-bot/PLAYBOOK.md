## Connector and environment notes

- **GSC MCP `analytics_query` ANSWERS ABOUT THE STALE `www.` PROPERTY ON `page` AND `query` DIMENSIONS EVEN WITH `siteUrl` SUPPLIED, AND DOES NOT ERROR. `["date"]` is correct; `["page"]`, `["query"]` and every `filters` array are not.** **RUN 22 SETTLED THE OPEN QUESTION: this is NOT caused by the phantom `legacy_*` accounts.** Run 22 cleared both accounts first, then pulled `["page"]` and still got the single `www.` row at 1 impression. **Two independent faults. Do not expect clearing the phantoms to fix the dimension bug.** Discriminator unchanged: pull `["page"]`, read row one, a `www.` URL means the wrong site. **The working route is the UI — see the next bullet.**
- **THE SEARCH CONSOLE UI IS A COMPLETE, RELIABLE PAGE- AND QUERY-LEVEL INSTRUMENT, READ VIA THE DOM (run 22).** This replaces the broken API dimensions entirely. Two things matter: **(1) `get_page_text` IS USELESS HERE — it returns a stale orphaned DOM container and will hand you the 3-month table while the screen shows 28 days.** Run 22 nearly logged 3-month figures as a 28-day window. **(2) Use `javascript_tool` instead:** `document.querySelectorAll('table')` returns the tables in load order — the LAST one is the live view, earlier ones are stale renders of previously-selected ranges. Map `[...t.rows].map(r=>[...r.cells].map(c=>c.textContent))` and strip the `Copy URL to clipboard|Open in new tab|Inspect URL` cruft from page rows. Full query set (337 rows at 28d, 692 at 90d) and page set come back in one call. Generative AI report: `/performance/search-analytics/ai?resource_id=…` — the `search_appearance=GENERATIVE_AI` URL param does NOT work.
- **GSC MCP `row_limit` defaults to 100 and silently truncates.** Rows return clicks-desc, then zero-click rows **alphabetically by (page, query)** — a low limit guillotines everything after roughly `/f…`. **Always pass `row_limit: 25000`**, which returns the whole dataset in one call.

- **GSC MCP: recrawl comes via the sitemap.** `indexing_submit`/`indexing_status` untested (prohibition 18). **`genai_query_insights` is NOT an AI-citation report** — heuristic pattern-matching on ordinary query data, by its own caveat. **Never quote it as citation evidence.** Its real use is isolating the conversational set: 33 of 343 queries, 671 impressions, zero clicks, 21 on `/fractional-cmo-vs-agency`.

Run 21 met the other kind: a working server, an operation that exists, and an authorisation layer refusing it — `accounts_manage remove`, `tabs_context_mcp` and `preview_start` were all denied by the classifier, not by the tool. **Distinguish them, and report a denial to Daniel as an ask rather than logging it as an outage.**

## Standing decisions

- **The verification protocol, the lastmod two-step and the noindex two-file rule are in the task file's FIXED RULES. Not restated here.** The two that have cost time: `check:lastmod` cannot fail before the content commit exists (Trap 5), so only the post-push pass means anything; and **pages built − noindexed = sitemap `<loc>` count**, checked after every structural change.
- Never state unsourced market statistics. Anchor cost claims on WSS's published ranges and reuse the bands on `/insights/fractional-cmo-cost-uk`.
- **Keep the "point them somewhere better" voice.** Every comparison should name the case where a competitor or a different model is the right buy — brand voice *and* what makes a passage worth citing.
- **When a change is defensible under two competing readings of the data, prefer it** over one needing the ambiguity resolved first.
- **Sweep the connectors before writing anything implying WSS expertise or client work.** The VC guide assumed fund-side experience; there is none. The real position is accelerator-side (Google for Startups, DeepMind, Techstars, GrowthMentor, several hundred founder sessions) — **a mentoring relationship, not client work. - **A hub page must not restate its spokes.** Run 3 spent a run undoing a self-competing cluster; do not rebuild one.
- **`src/data/growthTools.ts` is the primary source for what the free tools do** — not any page describing them (runs 13 and 14 both got this wrong). The Scorecard is **12 questions, ~4 min**, scoring **founder dependency** — not the five-layer framework on `/diagnose`. Never describe either in terms of the other.

The bytes never enter the parent's context and corruption becomes detectable rather than silent. Runs 19 and 21 did every file this way. This is the practical answer to Trap 4.
