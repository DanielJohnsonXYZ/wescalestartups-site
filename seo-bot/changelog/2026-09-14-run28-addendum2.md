# Run 28 ADDENDUM 2 — the Generative AI report, read for the first time in four runs

**The browser account blocker is SOLVED, and the fix is a URL parameter, not a settings change.**

## 1. `&authuser=1` SWITCHES THE ACCOUNT. Three runs of "blocked on Daniel" were one query string.

Daniel confirmed both accounts are signed into the same Chrome profile. Appending **`&authuser=1`** to the Search Console URL loaded the property as **`daniel@wescalestartups.com`** — verified by reading the account chip in the page, not inferred.

**Google then rewrites the path to `/u/1/…`, which is the durable form.** Runs 26, 27 and 28-main all recorded this as blocked on Daniel. **It was never blocked; nobody tried the parameter.** Run 27 correctly diagnosed the *cause* (wrong account) and then proposed only the two heavyweight fixes — re-signing Chrome, or adding a property user — without testing the cheap one.

**Standing method note, and this is the transferable lesson: when a Google property refuses, try `&authuser=0`, `1`, `2` BEFORE reporting an access blocker.** A multi-signed-in profile makes account choice a URL parameter.

**The working URL for future runs — use it verbatim:**

```
https://search.google.com/u/1/search-console/performance/search-analytics/ai?resource_id=sc-domain:wescalestartups.com&num_of_days=28
```

**`&num_of_days=28` is also load-bearing — see §2.**

## 2. THE DEFAULT RANGE IS 3 MONTHS, AND IT NEARLY PRODUCED A FABRICATED 2.4x RISE

On first load the report showed **Total impressions 814**. Against run 25's logged **337 (28d)** that reads as a 2.4x jump, and **it would have been wrong** — the report opens on **3 months**, not 28 days.

Clicking **28 days** (which appends `num_of_days=28`) gives the comparable figure: **305.**

**28-day series: 217 → 228 → 258 → 337 → 305.** **It went DOWN, by about 9%.**

**Caveat that applies to this number exactly as it does to the money pages:** run 25 read 337 on 2026-09-09; this is 2026-09-14. **Two 28-day windows five days apart share ~23 of 28 days. 337 → 305 is not an independent movement.** Do not describe it as a decline in AI visibility on this evidence. **What it does do is kill the "337 and rising" framing — the rise was never confirmed and the next reading moved the other way.**

**Add to the do-not-do list: read the Generative AI report without checking the date range.** The 3-month default is the trap, and 814 is the number it hands you.
